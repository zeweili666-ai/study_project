# Semester Study Planner

一个面向学生的本地学习规划工具。它把课程、课堂笔记、DDL、考试、科研任务和复习安排放进同一个日历里，让你每天打开就知道：今天该做什么，哪些截止日期正在逼近，哪份笔记该复习了。

## 项目亮点

- 课程、笔记、作业、考试和科研任务统一管理
- 日历直接显示每天安排，不用在多个页面来回跳
- 自动提醒未来 3 天内的 DDL、考试和科研截止
- 上传/导入课堂笔记后自动生成复习追踪
- 笔记支持复习难度：简单、普通、难
- 每条日历事项都能点击查看详情和安排原因
- 支持资料搜索，快速找到课程目标、笔记、任务和考试范围
- 本地运行，本地保存，适合个人学习管理

## 核心功能

### 课程管理

录入每门课的课程名称、老师/地点、上课时间和本学期学习目标。课程会作为后续笔记、任务和考试的基础关联信息。

### 统一导入信息

通过一个入口导入不同类型的信息：

- 每次课学习内容
- 课堂笔记
- 作业 / CW / 大作业
- 科研任务 / 组会 / 论文
- 考试范围 / 期末复习

导入成功后，系统会明确告诉你：

- 已保存为什么类型
- 所属课程是什么
- 后续会出现在哪里，比如日历、资料搜索、笔记复习

### 学习日历

日历是整个系统的核心视图。它会显示：

- 上课安排
- DDL 截止
- 考试日期
- 科研任务
- 今日安排
- 笔记复习

日历顶部还会提醒：

- 今天是哪一天
- 未来 3 天内有哪些 DDL / 考试 / 科研截止

日历支持类型筛选，可以只看课程、DDL、考试、复习或科研。

### 笔记复习追踪

上传或导入课堂笔记后，系统会自动安排复习时间。

复习间隔根据难度变化：

- 简单：5 天、10 天、21 天、45 天、60 天
- 普通：3 天、7 天、14 天、30 天、45 天
- 难：1 天、3 天、7 天、14 天、30 天

每次点 `已复习` 后，系统会记录复习次数，并自动安排下一次复习。

### 资料搜索

可以搜索已保存的学习资料，包括：

- 课程目标
- 课次内容
- 课堂笔记
- DDL / 作业详情
- 科研任务
- 考试范围

适合快速定位某个知识点、作业要求或老师强调过的内容。

## 本地运行

### 方式一：直接打开前端

直接用浏览器打开：

```text
index.html
```

这种方式不需要后端，数据会保存到浏览器本地存储。

### 方式二：启动 PowerShell 本地服务

双击：

```text
start_server.bat
```

或者在 PowerShell 中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\server.ps1
```

然后访问：

```text
http://127.0.0.1:5177
```

这种方式会使用项目目录下的 `data.json` 保存数据。

### 方式三：启动 SQLite 后端

双击：

```text
start_sqlite_server.bat
```

然后访问：

```text
http://127.0.0.1:5177
```

这种方式会使用 SQLite 数据库保存数据，并支持 PDF / DOCX 文件文字提取。

## 适合谁用

这个工具适合：

- 课程、作业、考试信息比较分散的学生
- 经常忘记课堂笔记复习的学生
- 需要同时管理课程任务和科研任务的人
- 想要一个本地、轻量、不依赖云服务的学习计划工具

## 设计原则

- 不让用户重复输入信息
- 日历优先，直接告诉用户每天该干什么
- 导入后明确说明信息保存到哪里
- 重要提醒靠规则，不依赖不确定的模型判断
- 尽量本地运行，保护个人学习资料
